# Trekking Management Application

A role-based web application developed as part of the Modern Application Development-I course.

# Project Overview

The Trekking Management Application is designed to provide a centralized platform for managing trekking activities.

The application follows a role-based architecture with three types of users:

1. Admin
2. Trek Staff
3. Trekker

A unified User table is used for authentication and role management, while separate Staff and Trekker tables store role-specific information.

## Technologies Used

- Flask
- SQLAlchemy
- SQLite
- Jinja2
- HTML
- CSS
- Bootstrap

## Features

- Admin Dashboard
- Trek Staff Dashboard
- Trekker Dashboard
- Trek Booking
- Booking History
- Role-Based Authentication
